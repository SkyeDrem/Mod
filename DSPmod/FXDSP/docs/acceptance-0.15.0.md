# 0.15.0 游戏验收

本次包含常驻科技坐标变更，需要完整退出游戏，再通过 r2modman 的 FXDSP Profile 启动。交易、存取和界面修改已编译并完成自动检查，实际 Unity 排版仍需游戏验收。

## 科技与分类

- 主科技页和升级页的两条交易科技线，均按一个节点间距整体右移；研究费用、前置和费率不变。
- 矩阵页仅有六种工厂矩阵；黑雾矩阵、能量碎片和其他黑雾专属掉落均在材料页。
- 消耗品页新增沙土。启用后“沙土可用”读取游戏原生沙土总量，存入减少它、提取增加它，不占背包、不经过交付塔。数量大于 int 上限时显示完整总量，单次操作仍安全限幅。

## 兑换数量和文字

- 建筑币左栏仅保留行情交易与五级兑换，删除独立的“建筑币”按钮。五个等级按钮仅把“蓝、红、黄、紫、绿”各字标为对应颜色。
- 单件兑换价和列表价格不显示小数，保留千位分隔；手续费和实际含费金额仍保留两位小数。
- 兑换数量输入下方有滑条，输入与滑条同步。上限取“含费可买数量”与“背包可回收数量”中的较大值，买入、回收按钮仍分别校验，不能以滑条越过资金或物品限制。
- 对应等级未研究时，用加大的红色文字显示需要的科技，双向兑换和数量滑条不可用。

## 账户、持仓与记录

- 可用和总权益恢复两行，左对齐，长数字自动适配字号。
- 账户盈亏、全部持仓、右上角持仓、结算卡片、操作记录和底部操作提示统一显示千位逗号及两位小数，例如 `+12,345.68`。入场价、行情价和爆仓价仍保留原有四位小数。
- 单市场当前持仓和全部持仓中的“做多”显示红色，“做空”显示绿色，方向旁的其它内容维持原色。
- “最近记录”更名“操作记录”。每行按实际字体宽度和可用宽度截断，不再固定 25 字符；检查较长数字和中文记录是否靠近面板右边才省略。

## 首次进入与存取滑条

- 每个存档首次打开交易系统时进入原料选择页，弹出留白介绍卡片；标题为“交易系统”，正文暂不填写。可点 X、卡片内外或 Escape 关闭。
- 保存、读档、F6 后不重复介绍；新存档重新显示。0.14 及更早的账户没有这项记录，本次升级后首次打开会显示一次，不清空资产。
- 存入、提取保持独立比例。先把存入设为 50%、提取设为 25%，再切换物品；输入数值应分别变成新物品可用量的 50% 与 25%，滑条位置不变。背包/平台来源切换也按此规则执行。
- 切换到空库存时数量为 0，但保留原比例；切回有库存的另一物品时仍使用该比例。手动输入数量会更新比例；同物品下库存变化仍刷新可用量，执行前重新检查实物。

169 项检查通过：核心 14、保证金/多账户 55、会话 27、背包/沙土/兑换 22、交付核心 15、原版交付接口替身 16、科技/目录/数量/显示 20。另用精确分数复算全部 175 种物品价值和 71 项兑换价格，保持 [定价文档](building-values-0.14.0.md) 同步。编译及接口替身检查不代替游戏中的字体、连线和点击验收。
