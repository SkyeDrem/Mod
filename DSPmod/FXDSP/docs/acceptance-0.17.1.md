# 0.17.1 前置科技图标与名称

修复自定义科技前置提示显示 `\;` 或缺少名称的问题。需要完整重启游戏，以重建原版行内图标与名称映射；科技 ID、研究进度、费用和交易数据不变，可继续使用本版已有测试存档。

## 游戏验收

1. 交易系统未研究时选中建筑兑换（1）或交易效率（1）。左侧红色前置提示应显示交易系统新图标及“交易系统 未解锁”，底部“需要 […]”也应有对应图标和名称。
2. 查看未满足前置的建筑兑换（2～5），确认提示引用上一等级的建筑兑换图标、名称和原版等级格式；效率（2～6）同理。
3. 在尚未研究、可研究、已研究状态间切换，确认没有裸露的反斜杠、分号或未解析标签。点击前置科技仍应定位到正确节点。
4. 原版科技（例如行星护盾）的提示保持原有图标、名称与行为。

## 修复依据与验证

- 原版科技节点读取 `_iconSprite`，而前置提示读取 `iconTagString` / `iconNameTagString`，再经 IconSet 的 TextIconMapping 得到图标和名称。仅设置 Sprite 不足以覆盖后一条路径。
- TechProto.Preload 根据 IconTag 生成两种文本标记；IconSet.Create 仅为非空 IconTag 建立映射。本版为每个科技分配独立的 `fx` 加科技 ID 标签，例如 `fx1951`、`fx7701`。
- 本机原版文本编码器只接受 1～6 字符标签，超长标签返回零；因此不能使用长命名空间。现有 12 个科技标签均为六字符，原版编码键唯一。
- `scripts/test-native-tech-tags.ps1` 直接调用本机原版托管解析器，24 个图标/图标名称标记回读均通过，并验证超长标签被拒绝。它只执行字典和字符串解析，不启动 Unity 或修改存档。
- 科技目录与文案等 23 项检查通过，Debug / Release 零警告、零错误。实际界面仍待上述游戏步骤确认。
