# 0.7.1 验收

部署完成后按 F6，无需重启。关闭交易平台查看右上角持仓面板。

- 标题为“持仓”，各品种使用图标，底部入口为“详情”；建筑币按既有约定不显示地基图标，以“币”文字表示。
- 紧凑宽度 212，展开宽度 248，展开每项只有一行，保留方向、杠杆、盈亏与平仓。3 项持仓时展开高度 166，原版为 271。
- 展开、收起、隐藏、恢复、详情跳转和逐项平仓继续有效，原配置模式保留。
- 大额盈亏使用 k/M 缩写以避免覆盖操作按钮，完整金额可在全部持仓页查看。
- 本次不修改行情、账户、费率或存档；实际图标与布局需游戏确认。

涨跌与性能分析见 [行情与扩展评估](market-performance-0.7.1.md)。
