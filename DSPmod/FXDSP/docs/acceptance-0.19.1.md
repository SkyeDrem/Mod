# 0.19.1 浮动盈亏百分比

账户栏、全部持仓页及右上角持仓面板的盈亏金额下面新增一行百分比。

计算：**浮动盈亏金额 ÷ 当前持仓实际保证金 × 100%**。金额已包含杠杆产生的盈亏，不重复乘杠杆；不使用下一笔开仓的保证金预览、可用余额、总权益或累计净投入作为分母。新增行与金额同色，保留正负号和两位小数；空仓或保证金非正显示“—”。

账户原有“累计盈亏 / 净投入”的收益率保持原逻辑。新指标只读，不改余额、持仓、开平仓费、爆仓价或存档。两种语言均显示相同的数字格式。

账户栏重新分配纵向间距，开仓按钮保持原位。全部持仓使用原有每行高度，盈亏金额与百分比分上下两行。右上面板每项增加必要的一行，并按金额及百分比文字宽度调整，平仓按钮仍居中可点击。

## 验证与验收

完整测试 196 项通过，新增覆盖分母/符号/空仓/小数保证金、高杠杆不重复计算、计算不改变持仓与资产，以及账户和组合快照的一致性。Debug/Release 构建通过；常驻模块仍为 0.19.0，核心更新至 0.19.1。

按 F6 后重新打开平台：检查金额下的百分比，修改开仓滑条应不改变既有持仓的百分比；打开全部持仓、右上面板，对照三个位置同一物品的读数；平仓后账户应显示“—”。切换中英文检查换行和按钮，当前价格、滑条、平仓和存取仍正常。实际 Unity 排版仍需游戏验收。
