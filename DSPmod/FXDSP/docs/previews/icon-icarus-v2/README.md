# FXDSP 伊卡洛斯图标候选

使用内置 image_gen 绘制；256×256 PNG 只做尺寸导出。经典黄色头盔按用户提供的正面、侧面近景修正；手机替换为宇宙矩阵，沿用原 icon 深色底、青色切角边框与 FXDSP 字样。角色缩小以显示更多服装及坐姿；背景使用一组连续开收盘、不等长影线的红绿 K 线，不绘制水平连接线。

### 连续OHLC与不等长影线

```text
Use-case: precise-object-edit. Edit ONLY the BACKGROUND CANDLESTICK CHART of the supplied FXDSP icon. Keep the current smaller character framing, exposed waist/skirt/bent-knee pose, exact classic yellow Icarus head, white Universe Matrix cube, hands, clothing, cyan beveled frame and 'FXDSP' bottom band unchanged. The chart must look like a REAL continuous OHLC candlestick sequence with clear rises and falls, not a flat decorative row. Exactly EIGHT evenly spaced candlesticks on one common invisible time/price coordinate plane, behind the foreground character. Each candle's OPEN is exactly the previous candle's CLOSE, so the body edge at that shared price is horizontally aligned with the preceding body edge. RED rising candles have close above open; GREEN falling candles have close below open. Use this continuous sequence as the geometry guide (O,H,L,C): 1=(34,60,30,53) RED; 2=(53,58,35,42) GREEN; 3=(42,72,40,65) RED; 4=(65,68,43,49) GREEN; 5=(49,78,47,70) RED; 6=(70,74,45,56) GREEN; 7=(56,69,51,64) RED; 8=(64,76,39,46) GREEN. Map all prices consistently to vertical positions with higher prices higher on the image. Show visibly differing body heights and distinctly irregular upper/lower wick lengths: some short, some long, not identical symmetric sticks. This should create an undulating, connected market pattern, with tall elegant bodies/wicks inspired by the original Kurumi cover. The entire chart is a single chronological series running from left to right; some central bars may be hidden behind the helmet, but do not add independent extra rows or scattered candles elsewhere. Do not draw numbers, axes, connecting lines, dotted lines or labels: the OHLC numbers are construction guidance only. Keep enough dark navy negative space and make the chart secondary to the character. Opaque navy inside the badge; preserve existing transparent outer cut-off corners. Do NOT alter the character or the typography.
```

Keep every candle's existing body position, width, height, color, open/close alignment and vertical wick lengths exactly unchanged. Do not remove the top/bottom edges of the candle bodies themselves.
