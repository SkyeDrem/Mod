# 0.12.0 原生交付物流塔验收

本版按用户要求不处理旧交付存档迁移。重启 r2modman 的 FXDSP 配置后，使用新测试存档验收；普通逻辑的后续更新仍可使用 F6。

1. 原生制作面板的建筑分页应出现“行星级交付平台”和“星际交付平台”两个独立条目，悬停查看对应名称、图标、介绍和配方。机甲不能手工制作；制造台中可选择配方。分别投入 2 座行星物流运输站 / 2 座星际物流运输站，产出 1 座对应交付平台。
2. 制作面板、建筑币兑换页均不应有小型交付箱。交付物流塔不通过改造或建筑币兑换获取。交易平台顶部不再存在交付管理面板与绑定按钮。
3. 建成第一座交付塔，在原版塔窗口第一格选择铜矿，即绑定铜矿账户；第二座塔选择塑料，即绑定塑料账户。市场底部选择“交付平台”存取，两个品种各走自己的塔，无需解除全局绑定。
4. 同一座塔的其它格、另一座交付塔再次选择铜矿，应弹窗提示原占用塔的星球、塔类型、编号与槽位，不改变任何库存或绑定。普通原版物流塔不受此限制。
5. 空间翘曲器可在同塔多格及多座交付塔重复设置；专用翘曲器补给槽沿用原版。若启用其交易市场，存取默认使用位置顺序第一座已配置塔，数量合并该塔内所有翘曲器槽，避免重复计数。
6. 同一座交付塔可配置多种不同物品；每种普通物品全局只占用一个交付槽。取空后移除该物品，即释放其绑定，随后可在另一座交付塔设置；其它品种的绑定不应受影响。含扩展库存的槽位需先取空才能更换。
7. 打开交易平台后从塔窗口取走物品，返回点击原数量存入，应按最新库存拒绝或只记实际取走量。账户与实物不得重复入账。每座塔保持原版槽数、传送带、无人机、运输船和供需模式。
8. 保存/读档、F6 后，绑定应由塔的原生物品设置重新识别，库存与账户保持不变。拆除交付塔的剩余扩展库存会保留，在其它交付塔再次为对应物品设置槽位时自动恢复，不再使用独立管理面板取回。

两种塔沿用原版模型和图标资源，具有独立的原生制作条目与物品介绍。Native UI 排版、制造台生产与实际物流仍需要游戏验证；本地自检使用纯逻辑与最小游戏边界替身。
