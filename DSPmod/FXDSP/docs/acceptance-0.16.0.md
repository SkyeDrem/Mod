# 0.16.0 游戏验收

新增升级页科技 ID 及布局，需要完全退出游戏，再通过 FXDSP Profile 启动，以新测试存档验收。按用户既定要求不迁移旧兑换科技研究状态。市场、资金与交付存档格式没有变化。

## 科技布局、费用与名称

- 主科技页只保留“交易系统”，位置在原版战场分析基站科技左侧一个节点间距（本机原版对应坐标 13, -59）。它没有可见前后置连线。
- 升级页底部有“建筑兑换”五级和“交易效率”六级，两条独立横向升级线。建筑兑换应采用原版升级样式，显示等级及名称括号数值。
- 建筑兑换费用分别为蓝 200、红 400、黄 1000、紫 2000、绿 4000。对应等级只消耗这一种矩阵，费用直接在原版研究界面核对。
- 两条升级线首级仍以交易系统为隐式前置，保留研究门槛，不绘制跨页连线。六级费率与之前相同。

## 收益率与账户对齐

- 累计盈亏下面新增“收益率”。计算为本物品账户累计已实现盈亏 ÷（总存入－总提取），以带符号的两位百分比显示，颜色沿用红盈绿亏。
- 例如累计盈亏 25、总存入 200、总提取 100，收益率应为 +25.00%。浮动盈亏不进入分子；此指标不年化，不与其它品种合并。
- 净投入为零或负数时显示“—”，避免无意义的百分比或除零。
- “可用”后补两格全角空白，“总权益”后补一格全角空白，数字起点对齐；维持两行与千位分隔，不改账户精度或金额。
