## 判定口径

| 成就 | 条件 |
| --- | --- |
| 交易新人 | 首次成功开仓，存取和建筑兑换不算开仓。 |
| 第一桶金 | 首次主动平仓获得正净收益，扣除实际开仓费和平仓费。 |
| 浮亏不算亏 | 任一持仓浮动盈亏÷实际保证金≤−10%，按界面浮动收益率口径。 |
| 韭卡洛斯 | 开仓选择100%仓位、100倍杠杆且成功。满仓针对该品种可用余额，包含预留费用。 |
| 短线擒龙 | 开仓后≤180游戏tick（两根K线时长）主动平仓，扣费净收益>0。 |
| 耐心资本 | 持有时间超过1000，完成1001个90tick间隔；不累计离线现实时间。 |
| 价值投资 | 实际成交价≤0.8开多，实际平仓成交价≥1，主动平仓。使用Ask开多/Bid平多，考虑点差。 |
| 血本无归 | 开仓时选择100%仓位的该笔持仓随后爆仓。满仓标志会保存，不要求事后余额恰好为零。 |
| 盈亏同源 | 某品种累计已实现盈亏÷净投入曾≥100%，之后一次亏损平仓/爆仓使账户总权益<1，且净投入仍为正。提款本身不触发。<1表示不足提取一件完整物品，以容纳强平余款/小数。 |
| 开超市 | 同时持有≥10个市场仓位，包含建筑币市场。 |
| 炒币 | 首次在建筑币市场成功开仓。 |
| 逛超市 | 用建筑币累计成功买入≥10种不同兑换物品。兑换列表所有物品均计入，重复种类不增加，卖出回收不计。 |
| 进货 | 一次用建筑币买入且实际收到>100件兑换物品。按背包实际接收数量，失败订单及回收不计。 |
| A9 | 建筑币总权益>100,000,000，包含持仓浮动盈亏，不计背包建筑折价。 |
| 建筑自由 | 建筑币累计已实现净盈亏≥1,000,000,000，交易和兑换手续费计入。建筑回收收入是投入，不是获利。 |
| 工厂？不需要！ | 宇宙矩阵账户累计已实现净盈亏≥100,000。 |
| 龙虎榜一 | 某物品账户累计已实现盈亏÷净投入>10,000%，净投入须为正。 |
| 投资达人 | 以上其余17项全部完成。 |

净投入=总存入−总提取；不汇总不同物品的本金或盈亏。收益均沿用既有账户账本，不另造一套统计收益。

## 监测与存档

- 开仓/平仓/存取/兑换沿用既有事件；浮亏、持有时间、建筑币浮盈门槛借现有报价更新检查。普通空仓市场无需成就报价检查。没有新增逐帧全市场扫描、定时线程或持久行情历史。
- 完成相应成就后不再收集兑换种类、满仓标记或翻倍账户；三项报价相关成就都完成后取消报价监测；全部完成后撤销成就事件回调。
- 仅为未完成成就保存：最多10种兑换ID、每市场一个满仓开仓时间、每市场一个曾翻倍标志；完成成就最多18项，待展示最多18项。不会随交易次数无限增长。
- 成就状态在交易旁档快照v3中追加；兼容v1/v2与旧F6交接，账本格式保持v4，原型模块仍为0.19.0。
- 旧档仅补发能从当前持仓和累计净盈亏可靠证明的项目，不推测历史满仓、历史浮亏、历史购入种类或已消失的长线持仓。旧数据不足的条件从安装后开始记录。
- 成就绑定游戏存档；读回达成前的旧存档会恢复该时刻的进度。
