# FXDSP 0.4.0 验收

可保持游戏打开。部署完成后按 F6，再按 F8。无新增依赖，保留 0.3.0 账户、持仓及行情；不会重新创建本金。

1. K 线显示实体及上下影线，红色上涨、绿色下跌，平盘灰色。每 1.5 游戏秒跳价并新增一根，画面最多显示最近 60 根。实体连接前后报价，随机上下影线只作美术展示，不参与成交或强平计算；同一根影线不会因界面刷新、F6 或读档重抽。
2. 盈利数值红色、亏损绿色，做多按钮红色、做空绿色。
3. 仓位比例支持 1～100% 滑动及 25/50/75/100% 快选；界面预览保证金和开仓费。比例指本次保证金加开仓费占当前可用余额的比例。选择 100% 能正常开仓，微量舍入余额可能留存。
4. 杠杆拖动到 1×、37×、100×，开仓后确认持仓倍数。持仓中改变滑条仅影响下次开仓。沿用单笔逐仓模式。
5. 底部“存入”和“提取”分别输入不同整数，修改任一项不改变另一项或开仓比例。检查大号“背包可用”和“可提取”随操作更新，背包满时只扣实际收到的铜。
6. 手动平仓出现结算弹窗：本次净盈亏包含开仓和平仓费用，费用合计及返还金额正确；即刻开平仓通常因费用和价差亏损。按“知道了”或 ESC 关闭弹窗，底层操作不会被误点。
7. 持仓时关闭交易窗口，行情触发强平后自动显示爆仓结算。未投入的铜仍在可用余额。
8. 账户正常时无“铜矿账户已就绪”等页脚说明；暂停、账户读取异常及操作失败仍有必要提示。
9. 持仓时 F6，再 F8；核对账户、保证金、方向、倍数和行情延续。保存并重新读取后再核对一次。历史结算不会因读档或 F6 重复弹窗。

数值及存档由自动检查验证；滑条手感、原版字体、弹窗遮挡与实际背包操作仍需本次游戏内验收。
