# 0.19.0 英文本地化与验收

游戏语言为简体中文时保留原文，英语时显示英文；其它非中文语言暂以英文作为 Mod 文本回退，原版物品名称仍跟随游戏自身。无需安装配置管理器或新增语言依赖。

## 文本范围

覆盖平台菜单、资源与矩阵选择、账户、做多/做空、存取、K 线价格说明、持仓和右上 HUD、建筑币兑换、欢迎说明、操作记录、研究要求、错误/状态提示、两种交付平台、12 项科技及前置图标名称。

349 条基础翻译保存在 `src/FXDSP/Localization/en-US.tsv`，嵌入两个 DLL。每行是中文源文和英文，以制表符分开；换行以 `\n` 表示。核心渲染只使用普通字体材质及已验证的颜色标记，不添加 `<b>`。示例：

| 中文 | 英文 |
| --- | --- |
| 交易系统 | Trading System |
| 建筑兑换 | Building Exchange |
| 交易效率 | Trading Efficiency |
| 建筑币 | Building Coin |
| 行星级交付平台 | Planetary Delivery Platform |
| 星际交付平台 | Interstellar Delivery Platform |
| 浮动盈亏 | Unrealized P&L |
| 累计盈亏 | Cumulative P&L |
| 做多 / 开多 | Open Long |
| 做空 / 开空 | Open Short |

## 实现边界

翻译限制在本 Mod 工厂创建的文本及有原型对象归属标记的建筑/科技；不全局拦截原版 `Localization.Translate`，不向原版语言数组注入数据，不翻译其它 Mod 窗口。名称、描述、解锁效果及结论分别处理，前置行内图标仅更新自有标签的友好名称，保留图集与 UV。

原型内部 Name、ID、研究费用和配方不改，避免改变 LDBTool 的注册键。账户、持仓、手续费和 1.5+k/2 价格不变；保存的操作记录不重写，旧中文记录在显示时翻译。文本缓存有上限，关闭控件移除追踪；F6 不把脚本类型或翻译委托写入跨重载状态。

英语界面使用当前原版物品名称，资源和兑换目录在语言切换后刷新。静态标签重新翻译，动态数据正常刷新，不重置市场选择、账户或首次欢迎标志。首次提示已看过的旧档可通过“说明”重读。

按钮和兑换格名称按空间适当缩放，英文 HUD 保留紧凑布局并略宽，操作记录先翻译再测量裁切。欢迎全文按实际文字高度滚动，保留全部九段和 12 处颜色强调。

## 自动验证

完整 `scripts/test.ps1`：193 项通过，包括原有 179 项以及 14 项新增本地化检查。新增覆盖全部资源条目、金融数字/精度、多空颜色、旧记录显示不改存档、语言往返、建筑/科技独立翻译、外国同 ID 原型不受影响及前置图标映射只改名称。

Debug 与 Release 核心/常驻模块均构建通过，零警告零错误。中英文分别运行 `test-native-tech-tags.ps1` 与 `-English`，共 48 个原版图标名称标记通过；`test-native-introduction-text.ps1` 中英文模式分别通过实际原版颜色解析器的 12 处标记检查，英文模式调用实际编译的翻译资源。全源扫描确认中文字符串都有英文条目，价格生成校验保持 71 项正式价格一致。

这些是生产代码的托管测试、游戏边界替身及本机原版解析器检查；实际 Unity 的字体、窗口布局、语言菜单回调和物流过程仍需游戏内验收。

## 游戏验收

1. 本次两个模块均更新为 0.19.0，需要完整重启 FXDSP Profile；之后仅改脚本仍可 F6。
2. 在中文模式打开各菜单和说明，确认原文、九段说明、颜色、数量及资产正常。
3. 将游戏语言切为 English，检查六类入口、资源选择、账户、存取、全部持仓、HUD、操作记录及五级建筑兑换。确认切换保留当前余额、仓位、选择与费率，英文长标题/记录没有盖住操作按钮。
4. 检查未解锁科技的前置名称、科技标题和上下两部分文案，以及制造面板两种交付平台的名称和描述。
5. 打开 Help 阅读欢迎说明，核对 long/rise 为红、short/fall 为绿，全文可以滚动到最后，关闭和再次打开正常。
6. 执行一笔存取和开平仓，再保存读档、F6，确认资产和历史记录保持；切回简体中文检查原文恢复。
