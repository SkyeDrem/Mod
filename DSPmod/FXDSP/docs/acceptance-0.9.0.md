# 0.9.0 验收

部署完成后 F6，再 F8，无需重启。原启用品种、资金、行情与持仓保留。

1. 关闭平台，右上角没有展开/收起。每项只显示图标、两位小数浮动盈亏、平仓按钮；标题、隐藏/恢复和详情入口保留。建筑币继续用“币”文字代替物品图标。
2. 默认宽 128、行距 26，三项持仓高度 136；金额较大时适当增宽。取消 k/M 缩写，仍展示两位小数。
3. 平仓按钮完整横排显示，文字处于点击范围内。点第二项平仓只结算第二项，行情刷新导致列表重排时也不误操作其它市场；暂停时按钮禁用。
4. 账户、保证金、浮动/累计盈亏、平仓结算与兑换金额显示两位小数，手续费百分比显示两位。行情、入场、爆仓价格仍为四位；数量、杠杆和仓位比例仍按原整数控件使用。
5. 顶部为六个并列入口：原料、材料、武器、消耗品、矩阵、建筑币。原料通常为可采集矿物等，材料含合成材料与零部件，武器含弹药/炸弹，消耗品含燃料棒、增产剂、翘曲器、太阳帆、火箭等。
6. 四类物品各自只显示本类已启用市场，左下方分别为“选择原料/材料/武器/消耗品”。没有启用品种时直接打开本类选择页，启用后返回行情或点击左侧品种。
7. 切换空分类、启用品种、返回行情、跨分类查看持仓详情，再切回矩阵/建筑币，检查没有显示错误分类的市场或遮挡导航。
8. 之前启用的铜矿会归原料，塑料会归材料，之前启用的弹药等自动归对应类别；分类不会生成本金、清掉余额、平仓或重置随机序列。

分类优先使用本机 ItemProto 的类型、isAmmo/isBomb、FuelType、CatalystType 等用途信息。存档只保存物品 ID，不保存显示分类，因此无需迁移资金数据。本次仍用 MarketBook v3 和既有 1% 兑换费率。

新操作消息使用两位金额；此前已保存的历史记录保留原文本。UI 字体、实际点击范围及分类目录仍需本次游戏内验收。
