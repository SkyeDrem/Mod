# 0.10.0 游戏验收

保持游戏打开，按 F6 更新，再按 F8。日志版本应为 `FXDSP 0.10.0 loaded`。本次未新增依赖或原型注册，不需要重启。

1. 原料选择页中检查水、氢、重氢、硫酸、有机晶体；消耗品选择页检查三种增产剂。在原料选择页点击材料/武器/消耗品/矩阵，右侧应仍是对应选择页。
2. 矩阵左栏点击“选择矩阵”，停用空仓矩阵；余额保留，报价停止。有持仓时不可停用。保存/读档与 F6 后检查选择状态和资金，再启用不应补算停用期间行情。
3. 最近记录应显示六行，金额两位小数，开仓如“开多14.48保证金”；旧记录也应按此展示。
4. 主平台内平仓应显示居中结算卡片，无左/上蓝边，无完成按钮；点击卡片内部或外部关闭。爆仓仍用警示色与“持仓已爆仓”标题。多项平仓时逐项关闭结算卡片。
5. 主平台开/关时右上角持仓面板均应存在；从右上角平仓不得打开主平台或弹出普通结算卡片，余额与持仓应随结算更新。隐藏/恢复、详情按钮仍可用。
6. K 线右侧四档价格应与四条水平网格对应，保留四位小数；爆仓标签在左侧，黑底仅比文字略宽，行情变化不应改变爆仓逻辑。
7. 建筑币左栏名称居中，出现一级蓝、二级红、三级黄、四级紫、五级绿兑换入口；切换等级后列表与选中物品同步更新。兑换页内没有等级选择器，双向 1% 手续费继续生效。

兑换等级依据本机原版 `ItemProto.FindPreTech()` 定位的解锁科技，遍历显式和隐式前置科技，取所需矩阵最高等级；无矩阵要求归一级。只有五级，若其他 Mod 引入宇宙矩阵解锁建筑则归第五级。该分类不添加新的研究限制，价格仍为之前的暂定比例。

本地编译和逻辑自检不替代 Unity 游戏内排版、点击与兼容性验收；上述项目待实际游戏确认。
