# 0.8.0 资源选择验收

部署完成后 F6，再 F8，无需重启。原有余额、持仓和行情保留；首次升级默认仍启用铜矿、塑料，矩阵及建筑币照常运行。

1. 进入“资源”，左侧底部有“选择资源”。选择页显示本机游戏中的原材料、材料、零部件与产品；建筑、地基、物流和战斗单位仍归建筑币兑换，不列入资源。
2. 点击任意未启用资源，它进入左侧行情列表并从零余额开始；仅浏览选择页不会为未选择品种创建行情账户。
3. 选择多个资源后返回行情，各市场仍独立使用本物品余额。选择页每页 28 项，左侧行情每页 8 项。
4. 空仓资源可点击“已启用”停用。余额和历史保留，该资源从运行循环移除，不生成报价、不推进市场时间/RNG，也不构建其图表。
5. 等待一段时间后重新启用，旧余额与当前价格保持，之后按新报价节奏继续原随机序列，不生成停用期间的历史价格。恢复时间锚时会记录一个同价采样点。
6. 有持仓的资源标为“持仓中”，不可停用，需先平仓。后端及存档读取也拒绝将持仓账户置为停用。
7. 可以停用全部资源，此时资源页保持选择界面；矩阵、建筑币和全部持仓页继续可用。
8. 保存/重读和 F6 后，资源选择、停用资金、启用品种持仓均保留。新存档恢复默认品种，不继承其它存档的资源选择或余额。
9. 多于九项持仓时，全部持仓页分页展示并可逐项操作，一键全部平仓仍操作所有持仓；右上角面板最多显示六项并标明其余数量，点击详情查看全部。

资源目录取自本机 `ItemProto`：ID 1000～1999、类型 Resource/Material/Component/Product、StackSize > 0，排除建筑兑换范围。此范围覆盖当前原版资源与中间产物；自定义 Mod 的其它 ID 不在本次支持范围。

保存采用 MarketBook v3，最多保留 256 个账户，读入上限 4 MiB；停用记录使用冻结字节缓存。旧 v1/v2 与更早单账户保持可读。回退旧 DLL 时应使用匹配的游戏存档与旁档。

本次自动检查覆盖资源惰性创建、停用不运算、余额保留、恢复不补算、持仓保护、旧档兼容及选择状态的 F6/旁档交接。选择页、分页和图标仍需实际游戏验收。
