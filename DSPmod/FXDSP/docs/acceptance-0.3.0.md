# FXDSP 0.3.0 铜本位保证金验收

## 更新方式

本次没有新增依赖，可以保持游戏打开。等 DLL 和 PDB 部署完成后按 F6，再按 F8 打开新窗口；不要在文件复制中途触发 F6。新增依赖、物品/科技原型注册等改动仍可能需要完整重启。

用户已要求后续停止使用子智能体，此约定也已保存在根目录 AGENTS.md。

## 窗口与字体

- 标题应为“FXDSP 铜本位交易平台”，右上角为普通 X 关闭按钮。
- 文字和按钮不再使用制造台发光字体材质及 HDR 高亮，窗口增加深色实底。
- 检查账户数字、报价、输入框、预设按钮、X 和图表是否清楚；不同 UI 缩放下仍应可拖动和关闭。
- 按 ESC 先取消输入，再关闭窗口；数字输入不应触发建造热键。

## 铜作为余额、保证金与盈亏单位

1 个实体铜矿存入 = 1 铜余额。小数铜可以作为盈亏留在账户；提取时按整数兑换回背包铜矿，不丢弃小数。

交易标的是模拟指数，并非铜矿兑换自身的价格。指数涨跌用于计算合约收益，所有资金仍属于铜矿市场，不能换成铁、矩阵等其它物品。

账户显示可用铜、保证金、总权益、浮动盈亏、已实现盈亏和总盈亏；不再显示独立“结算额度”。

## 开仓与平仓

1. 旧版平台铜矿应自动变成铜余额；也可存入少量未喷涂铜矿测试。
2. 数量框用于“开仓保证金 / 存取数量”，默认 1 铜。保证金需另留开仓费用，不能把全部可用余额无余量地投入。
3. 点击杠杆按钮，在 **1 / 2 / 5 / 10 / 20 / 50×** 间切换。
4. 点击“做多 / 开多”或“做空 / 开空”。首版同时只持有一笔逐仓仓位。
5. 做多时上涨获利、下跌亏损；做空方向相反。浮盈会直接显示为铜。
6. 点击“全部平仓”，保证金和结算结果回到可用铜。即使数量框为空，平仓仍应可用。
7. 检查平仓前后权益与盈亏，小额即时往返因价差与费用通常亏损。

报价仍约每 5 游戏秒推进；名义价值 = 保证金 × 杠杆。开仓与平仓费率均为名义价值的 0.1%，平仓费按当时指数折算的价值计算。浮动盈亏包含买卖价差，未预扣未来平仓费；已实现盈亏包含已收费用。

## 逐仓和爆仓

仓位价值接近“初始保证金的 5% + 预计平仓费”时自动强平。高杠杆更容易触及；行情跳变时也不会倒扣未投入的铜余额，不形成负债。

保证金和未平仓浮盈不能直接提取；可用铜仍可以提取。测试高杠杆时观察仓位清空、最近记录中的“爆仓结算”，以及未投入余额是否保留。

## 旧账户迁移与保存

- v0.2 平台实物铜矿按数量 1:1 转为铜余额；不乘行情。
- 旧结算额度按旧版最后的买入报价与原手续费率折算成铜，保留小数；这一步只迁移一次。
- 原行情、历史、随机状态和存取流水保留；新仓位随游戏保存，F6 也保留。
- 先记录余额与仓位，F6 后再 F8，检查余额、方向、杠杆和入场价；再保存并重读同一存档检查。
- 账户升级后，新快照包含保证金模型数据，应继续使用新版本读取；旧 DLL 备份不能单独把新存档变回 v0.2。

基础世界/tick 匹配和旁档限制沿用上版，游戏存档与 .moddsv 应一起备份。视觉、原版存读档与真实 F6 效果仍由游戏验收确认。
