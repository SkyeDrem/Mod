# 0.18.2 材料种类定价与说明修复

正式采用已确认的“仅材料种类变化”方案：每道单件价值 = 投入材料价值总和 ×（不同输入物品种类数 + 1）÷ 本批总产出件数。原矿基准、多配方及联合产物分摊沿用原约定，不加时间倍数。中间保留精确分数，最终兑换价向上取整，买卖手续费另计。

关键正式价格：普通传送带 8、高速传送带 486、极速传送带 6,990、行星物流塔 459,600、星际物流塔 2,201,920、轨道采集器 15,990,200。全部 71 项见 [定价与配方](building-values-0.14.0.md)，四套历史比较见 [方案对比](building-price-scenarios.md)。

说明中的问题是未被原版文字网格解析的 `<b>` 标记泄漏，并非中文编码损坏。所有加粗标签已移除，统一采用原版支持的颜色标记强调；开多、上涨红色，开空、下跌绿色，其他重点青色或金色。用户九段原文保持不变，说明滚动与再次阅读入口保留。

本次更新核心脚本至 0.18.2，常驻模块保持 0.18.1；没有改建筑、科技或配方原型。已有账户余额、持仓及研究状态不重置，旧操作记录按历史原金额保留，新兑换使用新价格。

## 验收

1. 游戏保持打开时按 F6，重新 F8 打开交易界面。标题栏“说明”全文应不再露出 `<b>`、`</b>` 或 Markdown 星号，多空与涨跌颜色正确。
2. 检查换行、滚动、关闭和再次打开说明，并核对九段正文完整。
3. 检查上述关键物品新单价；尝试买入与回收，数量及双向手续费应以新单价计算。
4. 保存、读档或再次 F6，确认余额、持仓及研究状态保持。仅价格表更新，不进行货币余额换算。

验证：正式生成器逐项对照离线方案一，比较脚本保留四套原始计算；完整模型测试、Debug/Release 构建及 ScriptEngine 重写检查。`scripts/test-native-introduction-text.ps1` 直接调用本机原版颜色解析器，检查实际编译文案的全部 12 个颜色标记、红绿对应和九段正文。实际字形与鼠标交互仍需游戏验收。
