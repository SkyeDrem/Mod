# FXDSP 0.6.0 验收

部署完成后 F6，再 F8。无需新增依赖或重启；旧铜矿、塑料和电磁矩阵账户继续使用，新市场零余额。

1. 顶部有“资源 / 矩阵 / 建筑币”。资源左侧为铜矿、塑料；矩阵左侧为电磁、能量、结构、信息、引力、宇宙矩阵，均有原版图标。
2. 账户只显示可用和总权益。仓位比例下方显示本次开仓保证金，拖动比例或改变杠杆时更新；已有持仓的保证金仍显示在“当前仓位”。
3. 杠杆支持原 1～100×滑条，并有 2/5/10/50×快捷按钮；开仓倍数应一致。
4. 普通平仓显示独立结算卡片，标题、整笔净盈亏大数字和返回余额可见。爆仓有琥珀色警示边框、背景、明确标题与“确认爆仓结算”按钮；与普通平仓可直接区分。
5. 建筑币左侧可在“行情交易 / 建筑兑换”切换。建筑币不作为原版物品加入背包，不在资源或矩阵之间转账。
6. 在建筑兑换中选择背包已有建筑，输入数量，点击“物品 → 建筑币”；再用所得建筑币兑换其它建筑或投入建筑币市场。
7. 兑换列表分页显示所有原版 `CanBuild` 物品，另明确包含地基 1131、物流无人机 5001、星际物流运输船 5002、配送运输机 5003、原型机/精准/攻击无人机 5101/5102/5103、护卫舰 5111、驱逐舰 5112。检查对应图标、背包数量、单位价值和合计。
8. 买入和卖出采用同一固定比例，原地往返不会生币。背包满时不扣币，部分接收时只扣实际数量；卖出仅给实际移出物品对应的币。
9. 九个市场可各自持仓、后台报价和结算。存档重读及 F6 后检查原有账户、建筑币余额、六种矩阵持仓及行情保持。

建筑兑换计入账户入金/出金，不视为合约盈利或亏损。物品价格不随建筑币行情浮动；行情只影响建筑币保证金交易盈亏。

纯逻辑、背包边界和旧数据迁移由自动检查覆盖；图标、排版和实际背包操作仍需游戏内确认。
