# DSP 交易平台 0.7.0 验收

部署完成后 F6 重载。无需新增依赖或重启，旧余额、持仓与行情继续使用；工程名和 DLL 仍为 FXDSP。

1. F8 打开窗口，标题为“DSP 交易平台”，外框没有旧模板带来的黑色边框/阴影。建筑币在市场、持仓和结算中均不显示地基图标。
2. 单市场文案为“累计盈亏”“当前持仓”“平仓”。累计盈亏沿用已结算盈亏数值，浮动盈亏单独显示。
3. 建筑兑换中，将数量设到可以买入/回收，保持鼠标停在按钮上观察。无资金或库存变化时，按钮亮度应稳定。修改数量后仅按最终可操作状态切换。
4. 兑换双向手续费 1%。例如 100 建筑币原价物品，买入支付 101，回收实得 99。操作前显示费用、买入总额和回收净额；背包只接收部分时按实际数量扣款和计费。手续费计入累计费用/已结算盈亏，物品原价计入入金/出金。
5. 持仓后的爆仓价标签位于 K 线图左侧，超出范围时的箭头仍保留，右侧最新 K 线不被标签遮挡。
6. 顶部“全部持仓”展示九个市场中所有现有持仓，分别列出保证金、入场价、最新价、爆仓价和浮动盈亏。逐项“详情”进入相应市场；逐项“平仓”只操作对应市场。
7. “一键全部平仓”一次结算所有现有持仓，按各自币种返还余额。沿用逐市场结算提示，不将不同物品收益相加。重复或刚好已经结算的平仓操作不影响其它市场。
8. 关闭平台后，游戏右上角显示持仓浮动盈亏。默认紧凑模式逐项显示，展开后有方向、杠杆和平仓按钮。收起后恢复紧凑；隐藏后仅保留小型“持仓”恢复入口。详情按钮打开全部持仓页。
9. 面板显示模式保存于 BepInEx 配置 `Interface.PositionHudMode`（0 紧凑、1 展开、2 隐藏），F6 后继续使用。平台打开时隐藏快捷面板以避免遮挡；返回游戏后恢复。
10. 暂停时仍可查看，但平仓/兑换禁用。退出/进入存档、F6 和存档重读后，检查旧账户、当前持仓及快捷面板均正常，旧 UI 和按钮监听不重复。

自动检查覆盖费用记账、部分成交、边界拒绝、指定市场平仓、批量预检、账户保存和迁移。亮度、边框、布局、原版界面位置与鼠标交互仍需游戏内确认。
