# 0.18.1 文案验收

本次按用户提供的原文替换两种交付平台的介绍，以及首次打开交易系统时的欢迎文稿。欢迎原文与富文本位于 `src/FXDSP/UI/IntroductionCopy.cs`，建筑介绍位于 `src/FXDSP/Core/DeliveryRecipes.cs`，后者同步编译到常驻原型模块。

开多、上涨采用红色；开空、下跌采用绿色。独立、仓位、杠杆、F8、物流塔交付平台、科技升级以青色加粗，建筑币与 FX战士伊卡洛斯以金色加粗。其余文案保留原句，不显示 Markdown 星号。

欢迎卡片使用原版普通字体材质，居中标题、左对齐正文，正文区域裁切并按实际文字高度滚动。滚动条在全文超出区域时显示。点击正文不会关闭；可通过 X、进入交易平台、外侧遮罩或 Escape 关闭。结算弹窗仍保留原有点击关闭行为。

旧档已经阅读过欢迎弹窗时不会强制重播，也不重置账户或首次提示标志。可通过交易平台标题栏的“说明”随时查看本次文稿。新档第一次进入仍自动提示。

## 游戏检查

1. 完整重启 FXDSP Profile，检查制造面板中两种交付平台的介绍均为新原文；配方、功能及翘曲器例外不变。
2. 打开交易平台，点击右上“说明”，核对全文、颜色、加粗及最后的祝语；检查宽屏与较低分辨率下内容可完整阅读、不会遮挡按钮。
3. 若出现滚动条，测试滚轮与拖动滚动条；内部点击不能意外关闭，关闭或进入交易平台后可正常操作。
4. 多次打开/关闭说明并按 F6 重载，检查没有残留遮罩、重复弹窗或异常；旧档不自动重复欢迎，新测试档第一次打开自动提示。

验证采用 Debug/Release 构建、编译后文案与富文本标记检查、部署文件及 ScriptEngine 重写校验。本次不修改金融计算或配方，不重复无关交易测试。实际 Unity 字体、滚动及原生建筑提示框仍需上述游戏验收。
