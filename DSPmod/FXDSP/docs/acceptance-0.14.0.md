# 0.14.0 游戏验收

本次修改常驻模块中的科技布局、等级名称及配方提示类型，需要完整退出游戏，再用 r2modman 的 FXDSP Profile 启动。按既定约定使用新测试存档验收；未宣称已经验证 Unity 实际排版。

## 科技树

- 主科技页底部应显示“交易系统”“建筑兑换1级”至“建筑兑换5级”，不再附带多余的 `(1)`。
- 升级页底部应显示“交易效率”及原版括号等级 1～6，名称中不再重复“1级”等字样。
- 节点遵循原版横向四格间距并对齐，交易系统只在当前分页连向一级兑换；不应再有连到另一页位置的长竖线。效率一级仍要求交易系统，但该前置不绘制跨页连线。
- 没有新增手绘图标，本版继续复用物品图标。之后可制作独立 PNG/Sprite 资源，并注册为科技图标。

## 建筑兑换与报价

- 建筑币左栏“交易”标题居中。兑换物品格有独立底色：未选且未满足条件最暗；背包中有该物品并已研究对应兑换等级为中等亮度；选中物品最高亮度。鼠标移动和刷新不应造成可点击状态频闪。
- 从背包移入或移出物品，底色应随可用数量刷新；研究前不能双向兑换，选中高亮只是导航状态，不越过研究门槛。
- 所有 71 项建筑及单位按 [定价文档](building-values-0.14.0.md) 的整数价值双向兑换，手续费另计。例如传送带单价为 6，原价买入 10 条为 60 建筑币，费用按当前研究等级计算。
- 对照文档抽查地基、传送带升级链、物流塔、黑雾高级制造建筑及战斗单位；报价不再采用先前的占位价格。

## 行情品种完整性

- 材料选择页包含存储单元、硅基神经元、物质重组器、负熵奇点、虚粒子；矩阵页包含能量碎片及原有六种矩阵。
- 奇异湮灭燃料棒、黑雾引力透镜等其它可堆叠产品均可选择。新档仍默认不勾选任何物品市场，建筑币常开。
- 本机原型表共 175 种物品：103 种行情品种、71 项兑换物品及独立沙土，全部归属明确。沙土不是背包实物，不出现在行情目录。
- 黑雾品种启用后可独立存取、开平仓、保存和停用；不同物品仍不能互换账户余额。

## 交易窗口与制造提示

- 账户文字左对齐，“可用 / 总权益”同一行；浮动盈亏、累计盈亏、保证金和杠杆文字加大。“当前持仓”及其方向、入场价等文字也加大，检查有无截断或碰撞。
- 行星级、星际交付平台在制造面板显示成品名称与原版耐久度、耗能等参数，保持各自原版塔的参数。配方仍只能由制造台生产，分别消耗 4/5 座对应塔、标称 60 秒。
- 交付平台仍不加入建筑币兑换。

## 自动验证

`scripts/test.ps1` 检查交易、资金、保存、交付和新目录；`python scripts/generate-building-values.py --check` 使用精确分数复算 175 种物品及 71 项兑换价格，并检查源码和文档同步。真实原版科技图标位置、文字换行和点击效果仍须上述游戏检查。
