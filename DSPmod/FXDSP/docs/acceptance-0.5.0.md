# FXDSP 0.5.0 验收

部署完成后可直接 F6，再 F8。沿用现有依赖，不注册新原型；原有铜矿余额、持仓和行情保留。

1. 顶部可以切换铜矿、塑料、电磁矩阵。新市场可用余额为零，不从铜矿划转本金。先从背包存入对应物品，再开仓交易。
2. 存取区分别显示“背包可用”“可提取”及大号整数数字；即使数量为零也应明确显示 0。两个输入框各自生效；切换市场后读取的是对应物品。
3. 持仓后，图表显示爆仓价虚线与价格。阈值在当前图表范围外时，虚线显示在边缘并有上下箭头。平仓后该线消失。
4. 爆仓线按实际报价、买卖价差、费用取整和维持保证金规则计算。影线仍只是美术效果，不因装饰影线碰到爆仓线而结算。
5. 分别存入三种物品，在不同市场开仓。切换市场不会改变其它市场的余额和持仓；其它市场后台继续报价、结算。多个爆仓提示会依次显示，弹窗明确对应物品。
6. 界面不再出现“1.5 秒/根”、配色解释及模拟/原型说明；保留必要资产、操作和风险信息。
7. 三个市场分别核对存取、盈亏与提取物品。持仓时 F6 后再次打开，三个账户均应保留。保存后重读，核对所有账户及行情延续。

新多账户数据仍使用原存档外层与 F6 缓存位置，但内部改用包含三个账户的容器，读取兼容 v0.2、v0.3、v0.4 单账户格式。回退旧 Mod 时应同时使用匹配的游戏存档和旁档，不能仅回退 DLL。

物品 ID：铜矿 1002、塑料 1115、电磁矩阵 6001。塑料与矩阵 ID 对照核对了 [物品映射代码](https://github.com/Eidosper/DSPnobelt/blob/main/no_belt.py) 和 [配方数据代码](https://github.com/Eidosper/DSPnobelt/blob/main/recipes.py)。
