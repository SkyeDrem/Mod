# 0.17.0 科技图标验收

本版把已确认的概念图接入原版科技 UI，包含交易系统、建筑兑换 I～V、交易效率 I～VI 共 12 个图标。图片嵌入常驻模块，需要完整重启游戏；F6 只能重载交易脚本，无法替换已经载入的图标缓存。

1. 通过 FXDSP Profile 启动游戏。日志应出现 `Loaded 12 custom FXDSP technology icons.`，不应出现图集读取或字段设置错误。
2. 主科技页交易系统从铜矿图标换为主脑/交易接入图形；位置保持在战场分析基站左侧，研究费用与文案不变。
3. 升级页建筑兑换五级显示建筑和双向箭头，罗马数字 I～V；交易效率六级显示主脑和降佣箭头，罗马数字 I～VI。检查顺序、方向和缩放是否正确。
4. 分别检查未研究、选中、已完成状态，以及节点、展开详情、研究队列中的显示。周围应透明，没有绿色方底、琥珀展示框、残留连线或邻格图案。
5. 原版边框、背景、状态颜色和文字仍由游戏绘制。确认白色图形清晰、没有过曝或暗色描边，小尺寸仍能区分两条升级线。
6. 关闭再打开科技树、切换分页、保存/读取、F6 后再次打开，应保留图标。交易账户和玩法不因图标改变。

资源位置：[生产图集](../src/FXDSP.DeliveryBootstrap/Assets/technology-icons.png)，[导入和生成说明](../src/FXDSP.DeliveryBootstrap/Assets/README.md)。原始概念图保留在 docs/previews。

本地验证覆盖 12 格透明资源、边界、有效不透明度、归一化导入尺寸、Debug/Release 构建及 DLL 资源校验。真实 Unity 显示仍需按上述步骤确认；没有为纯美术接入重复运行未修改的交易模型检查。
