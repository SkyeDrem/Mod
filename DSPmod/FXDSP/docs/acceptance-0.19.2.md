# 0.19.2 收益率与持有时间

- 交易账户：浮动盈亏下明确显示“收益率”；浮动、累计盈亏保留标题与金额，去掉金额后的物品名。
- 全部持仓：盈亏金额、收益率和持有时间分别占独立列，操作按钮保留。
- 当前持仓：持有时间从开仓起累计，按 `floor((当前游戏 tick − 开仓 tick)/90)` 显示完整 K 线间隔数，不写单位。开仓显示 0，经过一个间隔显示 1，不受 120 根历史保留上限影响。沿用已保存的开仓时刻，不改存档格式。
- 右上角持仓面板保持 0.19.1 的显示和布局，不增加持有时间。
- 平仓/爆仓结算：收益率为本次净盈亏除以该笔保证金，包含实际已付开仓费和平仓费。持仓浮动收益率仍按显示的浮动盈亏除以保证金，未额外预扣平仓费。
- 新操作记录显示平仓/爆仓金额和收益率，省略重复物品名以便一行显示；历史记录没有保证金信息时不补造百分比。
